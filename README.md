# yggapi

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run server.ts
```

Populate .env
```
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=http://localhost:3000
TURSO_CONNECTION_URL=libsql://dev-dckt.aws-eu-west-1.turso.io
TURSO_AUTH_TOKEN=
UNSPLASH_TOKEN=
UNSPLASH_ACCESS_KEY=
RESEND_API_KEY=
UPLOADTHING_TOKEN=
VITE_MAPBOX_API_KEY=
ENV=testing
```
